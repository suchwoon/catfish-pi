# Noto Sans KR

`NotoSansKR.ttf` is the unmodified Noto Sans KR variable font distributed by
Google Fonts, stored here so the bot renders Korean text without depending on
fonts installed on the host machine.

- Upstream file: <https://github.com/google/fonts/blob/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf>
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
- Downloaded: 2026-09-27.

Keep the font and license together when distributing the application.
